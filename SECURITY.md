# Security policy

Lucena is an archived research project and is not operated as a hosted production service.

Please do not open a public issue for a credential, token, private dataset, or exploitable authentication problem. Report sensitive issues privately to the repository owner through the contact mechanism listed on the GitHub profile. Include a description, reproduction steps, affected component, and suggested mitigation when available.

Never commit API keys or real user data. Use `.env.example` for configuration shape and local environment variables for secrets.
